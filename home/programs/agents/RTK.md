# RTK

The Claude Code PreToolUse hook runs `rtk hook claude` to rewrite supported Bash
commands automatically. Do not run `rtk init`: Nix manages the hook and context.

- Use `rtk gain` or `rtk gain --history` to inspect token savings.
- Use `rtk discover` to analyze Claude Code history for missed opportunities.
- Use `rtk proxy <command>` when unfiltered command output is needed.
